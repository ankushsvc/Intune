# Intune Community Scripts

This repository is a public collection of automation scripts and tools for Microsoft Intune and related workflows.

## What is included

- `scripts/` - reusable automation scripts for Windows, PowerShell, and Intune management.
- `LICENSE` - MIT license for sharing and collaboration.

## How to use

1. Browse the `scripts/` folder to find scripts.
2. Review each script and its comments before running.
3. Customize the scripts for your environment.

## Contributing

- Add new scripts under `scripts/`.
- Include a short description or README in the folder if needed.
- Open issues or pull requests if you want to share improvements.
